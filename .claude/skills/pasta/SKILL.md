# Pasta usage

Follow the pasta MCP instructions to start the user requested workflow. Immediately ToolSearch for the pasta MCP instructions tool and call it, then load the rest of the tool schemas.

Follow the user request for a new workflow and call ExitWorktree immediately to reset old state the user wanted to drop - don't inspect the previous worktree and follow the users new instructions.
